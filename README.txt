TURF WARS — GitHub Pages publishing

1. Sign in to https://github.com/
2. Create a NEW PUBLIC repository named: turf-wars
3. On the repository page, choose Add file > Upload files.
4. Upload index.html from this package.
5. Click Commit changes.
6. Open repository Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Select branch main and folder /(root), then click Save.
9. Wait a few minutes and refresh Settings > Pages. Click Visit site when the link appears.

Expected URL pattern:
https://YOUR-GITHUB-USERNAME.github.io/turf-wars/

Important:
- Replace YOUR-GITHUB-USERNAME with your actual GitHub username.
- This is a static demo. Tracker data is stored only in the visitor's browser/device.
- Do not upload secrets or private data to a public repository.
